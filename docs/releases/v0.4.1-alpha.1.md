Faster camera and quality switching, a fix for an OBS crash, and fixes from the code audit.

**Preview release.** Tested on one phone (vivo V2437, Android 16) and one Mac (Apple M1, OBS 33.0.1). Other Android 10+ phones are expected to work but aren't verified yet. Please send a Device report (Issues → New issue) either way.

**Windows:** keep using the [v0.4.0-alpha.1](https://github.com/VaraKare/phonecam-obs/releases/tag/v0.4.0-alpha.1) Windows plugin. The newer Windows build passes CI but hasn't run on a Windows PC yet, so it isn't attached here. The new phone app works with it; switching camera or quality just takes the older, slower path (about 3 s).

## What's new

- **Faster switching.** Changing camera or quality while live keeps the connection to OBS, and OBS rebuilds its decoder in place. "Live ended" no longer appears during a switch.
- **Fixed: OBS could crash when you clicked Forget paired phones.** Forget now asks for a second click within 5 seconds.
- **Two PhoneCam sources:** only one source uses the phone at a time. The other says why, and it takes over when the first is removed, or hidden without "Keep the phone live while this source is hidden". To show one phone in several scenes, add the existing source (Add Existing).
- **OBS Properties keep "Last session ended: …"** until the next live, so you can still see why live stopped.
- **System changes no longer end live:** dark mode, font size, display size and language changes. Leaving the PhoneCam screen still ends live (background live is planned for v0.5).
- **USB:** a phone that stops answering shows "The phone isn't answering over USB…" instead of retrying silently.
- **Wording:** the phone says "computer" instead of "Mac".

## Tested on real hardware

| Check | Result |
|---|---|
| Phone + Mac: 5 camera and quality switches while live | All on one connection, no "Live ended" |
| Mac: "Last session ended" line | Shown after a session ended |
| Phone: dark mode switched from quick settings while live | Live kept going |
| Mac: two PhoneCam sources | Second waits with the message; hiding the first (keep-live off) hands over the phone; showing it again makes it wait; removing the other gives it back |
| Mac: Forget paired phones | One click asks again; no crash; pairing again works |

Not yet verified: the exact switch time (the phone didn't keep its log lines), Windows with this version, Smooth 60 fps, sessions over 13 minutes, measured latency, phones other than the vivo V2437.

## Install

- **Phone:** `PhoneCam-0.4.1-alpha.1.apk`. It updates v0.3 or v0.4 in place and keeps your pairings.
- **Mac (Apple Silicon, OBS 33):** `PhoneCam-OBS-plugin-macos-arm64-0.4.1-alpha.1.zip`. Quit OBS first, then follow its INSTALL.txt or the [README](https://github.com/VaraKare/phonecam-obs#install-one-time).

Check your downloads against `SHA256SUMS.txt`.
