# PhoneCam v0.5: live when you leave the app

Version 0.5.0-alpha.1 of the phone app (versionCode 13). The OBS plugins don't change in this version: use the v0.4.1 Mac plugin and the v0.4.0 Windows plugin.

## What's new

### Background live (on by default)

- Live keeps sending to OBS when you leave PhoneCam: another app, the Home screen, the Back gesture, or the screen off.
- A notification stays in the status bar for the whole session: **● PhoneCam is live to OBS · USB** (or **· Wi-Fi**) with a running timer and a **Stop** button. Tap it to open PhoneCam. Android also shows its green camera dot.
- **Swiping PhoneCam away from recent apps stops live.**
- The phone preview pauses while PhoneCam is off screen and comes back when you return; OBS stays connected.
- The first time you go live, Android asks to allow notifications. If you say no, live still continues in the background, but Stop won't show in the status bar.
- Turn it off in **Settings → While live → Keep live when you leave the app**. Live then stops when PhoneCam leaves the screen, as in v0.4.

### Picture-in-picture (on by default)

- Going Home during live shows the phone preview in a small floating window with a small **● 00:24** timer.
- Tap the window for its buttons: **Stop** ends live; the full-screen button opens PhoneCam.
- Closing the window keeps live running in the background (with the notification), if background live is on.
- Turn it off in **Settings → While live → Picture-in-picture when you leave**. It needs the phone preview to be on.

### Phones that close background apps

vivo, Xiaomi, OPPO and some other phones close background apps to save battery. **Settings → While live → Let PhoneCam run in the background** opens Android's settings for PhoneCam, with a hint for your phone's brand (on vivo: Battery, then allow background power use). If the phone closes PhoneCam during background live, the next time you open it PhoneCam says so and points to this setting.

### Record button

Start and Stop is now a round record button like a phone camera, with no text: a white ring with a red circle to go live, which turns into a red square while live. Screen readers hear "Start live" and "Stop live". Setup steps (camera access, camera check) still use a worded button.

### Settings during live

Settings opens during live, and live continues while you're there.

| Can change while live | Saved for the next live | Waits until you stop |
|---|---|---|
| Paired computers, typing a pairing code, background live, picture-in-picture, background battery hint, notifications, sounds, privacy | Phone preview, extra sharpening | Pairing by QR scan, custom quality, checking cameras again, research tools (they use the camera) |

## Rules this version changes

The owner decided on 21 November 2026 that a live session the user started may continue in the background, replacing "camera only while the app is on screen". The rules are in [AGENTS.md](../../AGENTS.md) and [PLAN.md](../PLAN.md): capture never starts in the background, a notification with Stop shows whenever it runs, and swiping the app away stops it.

## How it works

- `LiveService` is an Android foreground service of type camera. It starts with each session the user starts and stops with it. It holds a CPU wake lock during the session, and a Wi-Fi lock while live over Wi-Fi.
- MainActivity still owns the session. Leaving the screen is decided in `onStop` (a picture-in-picture window is still visible, so it doesn't count).
- `LiveStreamer.detachPreview` and `attachPreview` drop the preview from the camera request when the preview surface goes away and rebuild the capture session when it returns. The encoder and the connection to OBS stay open.

## Tested on hardware

vivo V2437 (Android 16) with OBS 33.0.1 on an Apple M1 Mac, 21 November 2026. Details: [research note](../research/VIVO_V2437_BACKGROUND_LIVE.md).

| Check | Result |
|---|---|
| Live, then Home (Wi-Fi) | Kept going; notification with Stop and the camera dot |
| USB only, Stop in the notification | Said "· USB"; Stop ended live and cleared everything |
| Screen locked 30 s, then unlocked | Kept going; preview and timer came back |
| Swiped away from recents | Live stopped; notification gone |
| Background live off, then Home | Stopped with the message on how to turn it on |
| Picture-in-picture on Home | Small window with the preview; OBS kept going |
| Stop in the small window | Ended live |
| Closing the small window | Live kept going in the background with the notification |
| Record button, Settings during live, small-window badge | Worked as described |

## Not verified yet

- The "phone closed PhoneCam in the background" message (vivo didn't close it during the tests).
- Long background sessions, and battery and heat over time.
- The Back button on Android 10 and 11, and picture-in-picture on Android 10 and 11.
- Phones other than the vivo V2437.
- OBS's own help text still says "Start live"; it changes with the next plugin update.
