# PhoneCam v0.7: Windows, one-click installers, better screen sharing, recording with the phone

Phone app and OBS plugins 0.7.0-alpha.1 (app versionCode 15). These are the released files, and each one was tested:

| File | Built from | Tested |
|---|---|---|
| `PhoneCam-0.7.0-alpha.1.apk` | 17512b9 | vivo V2437 with a Mac and with a Windows laptop |
| `PhoneCam-OBS-plugin-macos-arm64-0.7.0-alpha.1.pkg` and `.zip` | 17512b9 | Apple M1 Mac, OBS 33.0.2 |
| `PhoneCam-OBS-plugin-windows-x64-0.7.0-alpha.1-setup.exe` | 24f89cb (CI run 45231935828; same plugin code as 17512b9) | a Windows laptop with OBS freshly installed |

The Apple Silicon + Intel ("universal") Mac plugin is a test build only. No Intel Mac has run it, so it isn't released.

## What's new

### Windows is back in the release

- For the first time since v0.4, the Windows plugin is part of a release. It has the same features as the Mac plugin: control from OBS, microphone, screen sharing and recording options.
- **Installer:** `PhoneCam-OBS-plugin-windows-x64-0.7.0-alpha.1-setup.exe`. Quit OBS, double-click it, and choose **More info → Run anyway** (the preview installer isn't signed yet). It installs into OBS's plugins folder and appears in **Settings → Apps**, where it can be uninstalled completely.
- **adb on Windows:** unzip Google's SDK Platform-Tools, then put the `platform-tools` folder at `C:\platform-tools`. The plugin looks there.

### One-click Mac installer

- `PhoneCam-OBS-plugin-macos-arm64-0.7.0-alpha.1.pkg` installs the plugin for your user, with no Terminal step and no password. It replaces an older PhoneCam plugin by itself.
- The installer is unsigned: right-click it → **Open**, or **System Settings → Privacy & Security → Open Anyway**.
- The zip is still there for people who prefer copying the plugin by hand.
- The plugin's signature is now complete: `codesign --verify --strict` passes.

### Recording follows the phone (OBS source → Properties → Recording)

- **Stop OBS recording when the phone stops live**, on by default. Tapping Stop on the phone also stops the OBS recording, and so do the notification's Stop, the small window's Stop, OBS's "Stop live on the phone" and swiping PhoneCam away. A pulled cable or a lost Wi-Fi link **never** stops the recording, so a slip of the cable doesn't cost the take. Untick it to keep recording after the phone stops.
- **Start OBS recording when the phone goes live**, off by default. OBS starts recording when the phone's first picture arrives, so the file doesn't start black.
- Both cover OBS's recording, not streaming. The OBS log notes each time they act.
- How it works: on a deliberate Stop the phone sends OBS a short goodbye before it disconnects. A lost cable can't send one.
- **Tip:** OBS names the recording files. To start each name with PhoneCam, set **Settings → Advanced → Recording → Filename Formatting** to `PhoneCam %CCYY-%MM-%DD %hh-%mm-%ss`.

### Better screen sharing

- **Entire screen or one app** (Android 14 and newer). PhoneCam asks before Android's prompt, or uses your choice from **Settings → While live → Screen sharing shares**. Android 10–13 always shares the entire screen.
- **Phone sound:** a speaker icon in Screen mode sends the phone's own sound (videos, games, music) to OBS. It's off until you turn it on. Android counts it as audio recording, so it asks for the audio permission then. Choose **While using the app**: "Only this time" ends when PhoneCam leaves the screen, and PhoneCam asks again rather than quietly sending no sound. With the microphone also on, both are mixed. Some apps don't allow their sound to be captured.
- **Smoother:** screen sharing is capped at 30 fps. Phones with 120 Hz screens sent more frames than the link could carry, which built up delay.

### Ready for OBS updates

- Every plugin is built against one fixed OBS version, 33.0.1, whatever OBS the build computer has. OBS loads plugins built for its own version or older, so PhoneCam works on **OBS 33.0 and every newer version**, and an OBS update on the build computer can't break things for anyone.
- The OBS log says `[phonecam] Built for OBS 33.0 and newer; running in OBS …`. It adds a warning when a newer major version of OBS arrives.
- Every Monday an automatic check loads PhoneCam in the newest official OBS for Mac and Windows, so a problem is found before most people update.

### Smoother and steadier

- **Faster start:** the first picture reaches OBS 0.65–1.45 s after the tap over USB (v0.6: 1.7 s).
- **Clean pop-ups:** every choice (share what, quality, pairing code, settings) is a simple bottom sheet in PhoneCam's style.
- **A once-a-minute summary in the OBS log** while live: fps, dropped frames, the phone's battery and temperature, and whether the microphone and phone sound are on and arriving.
- **Fixes:**
  - hiding a source during Wi-Fi live can no longer stall OBS;
  - Wireless debugging connects only to phones you have already allowed;
  - the microphone permission is asked again instead of being turned off silently.

## Known limits

- **Audio tracks:** if OBS says the PhoneCam source "is not assigned to any audio tracks", open **Edit → Advanced Audio Properties**, tick **Tracks 1–6** for it, and unmute it in the Audio Mixer. Once is enough. The plugin's automatic fix didn't work in testing, so this step stays.
- **4K on Windows laptops:** Best (4K) dropped about 180 frames on the test laptop. 1080p (High) was smooth.
- **Pulling the cable** ends live on the phone (OBS keeps recording). PhoneCam doesn't switch to Wi-Fi by itself yet. Plug back in, or go live over Wi-Fi, and tap the record button.

## For developers

- `SDK_VERSION` in `tools/build_native.py` sets the minimum OBS for every build. Raise it only on purpose, and say so in the release notes.
- New tools:
  - `tools/sync_check.py`: clap test for sound and picture;
  - `tools/latency_clock.html`: camera-to-OBS delay from a screenshot;
  - `.github/workflows/newest-obs.yml`: the weekly newest-OBS check.
- Helper agents in `.claude/agents/` and [CHANGE_MAP.md](../CHANGE_MAP.md) list what has to change together.
